## 接线图

```
相机 USB-C 母座
      ↑ 插上
USB-C 公头（24pin 小板，A/B 两面都引出）
      │
      ├─ A7  D− ──[可选 470Ω]── GP28   Pico 串口 TX（open-drain）
      ├─ A6  D+ ── 470Ω ────── GP27   复位
      ├─ A5  CC1 ─┐
      ├─ B5  CC2 ─┴─ 5.1kΩ ── GND
      ├─ VBUS（A4/A9/B4/B9 任一根）── Pico 5V
      └─ GND（A1/A12/B1/B12 任一根）── Pico GND
```

备注：**A6/A7 不行的话，尝试 B6/B7。**

## 准确的物理连接

Pico 元件面朝上、Micro-USB 在顶部时，使用右侧排针：

| Pico 物理针脚 | 板上标记 | 转接板连接 |
|---:|---|---|
| 40，从顶部第 1 个 | `VBUS` | A4 `VBUS` |
| 38，从顶部第 3 个 | `GND` | A1 `GND` |
| 34，从顶部第 7 个 | `GP28` | A7 `D−` |
| 32，从顶部第 9 个 | `GP27` | 先经过 470Ω，再接 A6 `D+` |

转接板标签面朝上、USB-C 插头在顶部时，右列从顶部 A12 排到最底部 A1。
因此从底部向上数，A7、A6、A5、A4、A1 分别是第 7、6、5、4、1 个圆孔。
左列从顶部 B1 排到最底部 B12；B5 是从顶部数第 5 个圆孔。先短接 A5 与
B5，再从这个共用节点通过一个 5.1kΩ 电阻接到 A1 地。其他焊盘全部不接。

不要混用两组。备用方案是把完整的 A6/A7 对替换为 B6/B7：GP27 经过
470Ω 接 B6 D+，GP28 直连 B7 D−。不能同时连接两组，也不能把 A6 与 B7 组合。

### 可选的被动 Pico 2 监视器

第二块 Pico 不属于注入电路。只在诊断时，将它的物理针 34 (`GP28`)
接到一根待测的相机侧信号，物理针 38 (`GND`) 接公共地。
物理针 40 (`VBUS`)、物理针 32 (`GP27`) 及其他所有针都不接。
一次只监视 A6 或 A7 中的一根。第一块 Pico 仍是唯一的 VBUS 电源和发送器。

## 说明

- 相机侧是 USB-C 母座，必须用公头 24pin 小板才能接触引脚；
- 注入期间相机 USB-C 接 24pin 小板，不接电脑；
- D− 使用 open-drain，不要 3.3V 推挽；
- GP28 和 GP27 不能互换；
- GP29（MULTI_RX）当前不接；
- 470Ω：GP27 → D+ 必需；GP28 → D− 可选；
- 先把 CC1 和 CC2 并接，再从这个共用节点通过**一个** 5.1kΩ 电阻接地。不要把接线图理解为每个 CC 引脚各用一个电阻；
- VBUS、GND 各接一根即可，相机内部已经并联。

## 装配验收

Saiko 板只是裸转接板，不是成品恢复线。如果交给电子维修店或创客装配，
请提供本页并要求：

1. 使用短绝缘线，所有焊点绝缘，并加机械应力消除，避免裸板撬动相机插座；
2. 放大检查所有焊点；
3. 按接线图逐点测量导通，包括共用 CC 节点以及分开的 GP27/GP28 路径；
4. 连接相机前，检查 VBUS、GND、D+、D−、CC 及相邻焊盘之间没有短路；
5. Pico 3.3 V 不得连接到相机信号脚，也不得用只有 4 或 6 引脚的简化 USB-C 转接板替代。

不要用相机测试未完成的接线。应先完成并记录无源导通检查。

## 电池与复位

- 电池插着，相机正常开机；
- 脚本先开载波，再发 GP27 10 µs 低脉冲复位相机，然后整组重放；
- **有复位后不需要拔电池**；拔电池冷启动是旧的 v7 方法，当前不用。

### 操作者可见的复位测试

相机在不支持的附件接入后，会先显示 `USB Mode`，数秒后显示
`Check the connected device`。这个变化不需要 Pico 命令，不能证明复位成功。

要做无歧义测试，相机必须接转接板，不能接普通电脑线。等到
`Check the connected device` 稳定显示后执行：

```sh
.venv/bin/python pico/reset_only.py \
  --port /dev/cu.usbmodemXXXX --countdown 5
```

只有在 `NOW: reset pulse` 时已经稳定的警告立即消失、屏幕变黑，才算复位成功。
如果警告仍在，不要继续重复命令；先断电检查完整的 GP27 到 D+ 通路。

## Linux 面包板装配记录，2026-11-11

已购 Pico H 与无源元件通过以下相机连接前检查：

- 发送固件为 `zve10_uart_od 15`，开漏构建与安全空闲状态正确；
- 复位电阻实测 466-468Ω，CC 电阻实测 4.99kΩ；
- 相机未连接时，A4 VBUS 到 A1 地实测 4.90 V；
- 7,636 字节 stage1 生成五条记录，完整记录组可通过 Pico 重放，并恢复安全空闲；
- 相机用普通电脑 USB 线可正常枚举为大容量存储设备。

本次面包板转接器测试**没有**出现 stage1 长闪，也没有出现 fastboot 设备。
相机本身的屏幕变化和面包板接触变化干扰了复位观察，因此这只是未完成的
转接器装配，不是新的 fastboot 实机验证。未尝试写入 eMMC、SD 或 OTP。
运行日志与设备标识保持私密并由忽略规则排除。

### 两块 Pico 的被动诊断，2026-11-12

一块 RP2350 Pico 2 运行相同的 v15 固件，只把 GP28 作为无上下拉的被动输入。
可复用的 `pico/monitor_line.py` 在 RP2040 发送器工作时汇总跳变。
两块板多次通过固件身份和安全空闲检查。

- 一次 A6 观测在 729 个捕获窗口中看到 1,457 个普通 USB 跳变，
  证明被动监视器可观测相机侧 A6 节点。
- 之后面包板重接后，有界的 10 ms GP27 复位没有产生 A6 跳变。
  发送器焊盘在脉冲前、中、后均读低，GPIO 功能为 5 (SIO)，
  而监视器先前读到 A6 为高。
- 已发布 stage1 注入 12 秒期间，A7 保持低，1,213 个窗口中零跳变。
  相机 LED 没有闪烁，也没有 fastboot 设备。
- 万用表在 A6 和所报 GP27 节点均测得 2.20 V，但时间平均电压不能证明连续的点对点通路。

这些观测来自不断变化的面包板状态，彼此有冲突。它们说明
GP27 -> 470Ω -> A6 装配仍未解决；**不能**由此断定相机、BootROM 或 payload 有缺陷。
再次注入前，断电记录四段导通：GP27 到电阻输入（约 0Ω）、电阻两端（约 470Ω）、
电阻输出到 A6（约 0Ω）、GP27 到 A6 端到端（约 470Ω）。
然后必须让被动监视器看到有界的 10 ms A6 脉冲。未尝试写入相机存储。

两块 Pico 同时连接时，使用稳定的 `/dev/serial/by-id/` 路径。部署 UF2 前，
拔掉另一块板，并按 [Pico 发送器说明](../pico/README.zh-CN.md)核对目标 USB ID 和卷标。

## 换线到电脑

- payload 检测 VBUS 低 → 高；看到长闪后把 24pin 小板从相机拔下，换普通 USB-C 线接到电脑；
- Pico 5V 和 Mac 5V 会在相机 VBUS 上顶在一起，Pico 可能从 Mac 掉线，不影响已经在运行的 payload。

## LED

- 已发布镜像：一次长闪（0.4 s）表示 payload 活着；经验证的换线窗口仍为 30 秒；
- 本地重建的源码候选版：初始存活和 USB PHY 灯号之后，常亮表示
  **现在拔下转接板，插入普通 USB-C 线**。VBUS 先低后高前会一直常亮。
  如果始终不熄灭，说明未检测到换线，不会启动 DWC3 初始化；
- 换线成功后，短脉冲计数表示 DWC3 和 EP0 配置进度；
- 之后每 2 秒一次短脉冲：在等主机枚举；
- 停在第 N 个短脉冲：对应步骤没有返回。

## 停止 / 恢复正常启动

从仓库根目录：

```sh
python3 fastboot/pico/reset_only.py --port /dev/cu.usbmodemXXXX
```

发一次 GP27 复位、关闭载波，相机回到正常启动，不用拆电池。也可以直接断电/取电池：
payload 在 SRAM，易失。

## 边界

- 这是 BootROM 串口启动，不是运行时漏洞；需要专用接线和复位时序。
- 只写 SRAM；不写 eMMC、SD 或 OTP。
